## 📌 About The Project

**Student Login Dashboard** is a modern front-end student portal designed for **Computer Knowledge Hub (CKH)**.

The project provides an interactive student experience starting from a secure-style login interface and continuing into a responsive dashboard where students can access important academic and financial information.

The interface includes Student ID validation, dynamic CAPTCHA generation, dashboard navigation, profile management, fee status, payment options, payment confirmation, receipts and payment history.

The project focuses on creating a clean, minimal and professional user experience with responsive layouts for desktop, tablet and mobile devices.

> ⚠️ **Important:** This project is currently a front-end prototype. Authentication and payment interactions are implemented for demonstration purposes and are not connected to a production backend or real payment gateway.

## ✨ Features

### 🔐 Student Login

- Student ID validation
- Dynamic CAPTCHA generation
- Randomized CAPTCHA characters
- CAPTCHA regeneration
- Real-time input validation
- Login authentication animation
- Success confirmation before dashboard access

### 📊 Student Dashboard

- Responsive dashboard layout
- Academic overview
- Student-friendly navigation
- Desktop sidebar navigation
- Mobile slide-out navigation drawer
- Smooth screen transitions

### 👤 Student Profile

Students can access their profile information and academic details through the dedicated profile section.

### 💰 Fee Management

The portal includes a fee management interface where students can view their fee-related information and payment status.

### 💳 Payment Interface

The payment section provides UI flows for multiple payment methods:

- UPI
- Credit Card
- Debit Card
- Net Banking

### 🧾 Payment Confirmation

After completing the payment flow, the dashboard provides:

- Payment confirmation
- Transaction details
- Payment method information
- Receipt access

### 📜 Payment History

Students can access their payment history and ledger interface to review previous transactions.

### 🖨️ Receipt Printing

The project includes dedicated print styling for the payment receipt.

### 📱 Fully Responsive

The interface is designed to work across:

- 🖥️ Desktop
- 💻 Laptop
- 📱 Tablet
- 📲 Mobile
